# VRC World Gallery

VRChatワールド内のワールド紹介展示を、GitHub Pages経由で外部更新するためのデータ置き場です。

写真・ワールドID・ワールド名・作者名をGitHub側で更新することで、VRChatワールドを再Build / 再Uploadせずに展示内容を変更できます。更新できるのは、Unity側へ事前登録したフレーム数と画像URLの範囲内です。

## 構成

以下の例ではRepository名を `VRC-WorldGallery` としています。URL内のユーザー名とRepository名は、自分の公開先に置き換えてください。

```text
VRC-WorldGallery/
├─ README.md
├─ worlds.csv
└─ images/
   ├─ 001.jpg
   ├─ 002.jpg
   ├─ 003.jpg
   └─ ...050.jpg
```

## GitHub Pages

GitHub Pagesを有効にしたRepositoryで、CSVと画像を公開します。

公開URLは以下の形式です。

```text
https://USERNAME.github.io/VRC-WorldGallery/
```

画像：

```text
https://USERNAME.github.io/VRC-WorldGallery/images/001.jpg
```

展示データ：

```text
https://USERNAME.github.io/VRC-WorldGallery/worlds.csv
```

## 画像ファイル

画像は `images` フォルダ内に配置します。

ファイル名は3桁の連番を使用し、CSVの `slot` 番号と一致させます。

```text
slot 1  → images/001.jpg
slot 12 → images/012.jpg
slot 50 → images/050.jpg
```

画像IDを個別指定する項目はありません。`slot` を決めると画像ファイル名も決まります。

推奨仕様：

- JPEG形式、拡張子は小文字の `.jpg`
- 横長は16:9、縦長は9:16
- 多数の写真を並べる場合は、まず512 × 288px／288 × 512px程度から調整する
- 写真は事前に適切なサイズへ縮小する

画像ファイルの容量と、VRChat内で展開した画像のメモリ使用量は異なります。メモリ上限で読み込めない場合は、画像の解像度を下げてください。

## worlds.csv

展示情報は `worlds.csv` で管理します。

```csv
slot,enabled,world_id,world_name,author,orientation
1,1,wrld_00000000-0000-0000-0000-000000000001,海辺のワールド,AuthorA,
2,1,wrld_00000000-0000-0000-0000-000000000002,夕暮れのワールド,AuthorB,p
3,0,,,,
```

上のワールドIDは形式を示すための例です。実際に紹介するワールドのIDへ置き換えてください。ワールドのWebページURL全体ではなく、`wrld_` から始まるIDを指定します。

### 項目

| 項目 | 内容 |
|---|---|
| `slot` | 展示番号。1〜50のうち、Unity側に配置・登録した枠を使用 |
| `enabled` | `1` = 表示、`0` = 非表示 |
| `world_id` | 紹介するワールドのID。`wrld_` から始まる文字列 |
| `world_name` | 表示するワールド名 |
| `author` | 表示するワールド作者名 |
| `orientation` | 空欄または `l` = 横長、`p` = 縦長 |

`orientation` によって横長／縦長のフレームへ切り替わります。壁掛け型／卓上スタンド型の選択と配置はUnity側で行います。

横長だけを使う場合は、`orientation` 列を省略した5列CSVでも使用できます。

```csv
slot,enabled,world_id,world_name,author
1,1,wrld_00000000-0000-0000-0000-000000000001,海辺のワールド,AuthorA
```

ヘッダーの項目名と順序を維持し、各行の列数をヘッダーに合わせてください。6列のまま横長にする場合は、末尾のカンマを残して空欄にします。

文字コードはUTF-8を使用します。

ワールド名や作者名にカンマを含める場合は、フィールドをダブルクォートで囲みます。文字としてのダブルクォートは `""` と重ねます。

```csv
1,1,wrld_00000000-0000-0000-0000-000000000001,"海,空のワールド","Author ""A""",l
```

フィールド内の改行は使用しないでください。行順ではなく `slot` で割り当てるため、同じ番号を重複させないでください。

## 写真とワールドを追加する

例として12番目の展示を追加する場合：

1. Unity側にslot 12のフレームと画像URLが登録されていることを確認
2. 写真を横長16:9または縦長9:16に用意し、適切なサイズへ縮小
3. `012.jpg` にリネームし、`images/012.jpg` として追加
4. `worlds.csv` に展示情報を追加

```csv
12,1,wrld_00000000-0000-0000-0000-000000000012,ワールド名,作者名,l
```

5. Commit / Push
6. GitHub Pagesへの反映後、VRChat側で「再読み込み（自分のみ）」を実行

登録済みの枠へ追加する場合、VRChatワールドの再Uploadは不要です。配置した枠数を増やす場合は、Unity側の変更と再Uploadが必要です。

## 展示を非表示にする

画像を削除せず、`enabled` を `0` に変更します。

```csv
12,0,wrld_00000000-0000-0000-0000-000000000012,ワールド名,作者名,l
```

再表示する場合は `1` に戻します。CSVから行を省略したslotも非表示になります。

## 写真を差し替える

同じ展示番号を維持したまま写真だけ変更する場合は、同名ファイルを置き換えます。

```text
images/012.jpg
```

URLは変わらないため、Unity側の設定変更は不要です。横長から縦長へ変更する場合は、CSVの `orientation` も `p` に変更します。

## ワールド情報を変更する

該当するslotの `world_id`・`world_name`・`author` を編集します。

写真も変更する場合は、同じslotに対応する画像ファイルを差し替えてください。展示内容を別の枠と入れ替える場合も、CSVと画像をセットで変更します。

## VRChat側

Unity側では、ワールド写真展のManagerへ公開先のURLを事前登録します。

```text
Rusc_Lod → ワールド写真展 → GitHub Pages URLを一括設定
```

Managerと公開先のルートURLを指定すると、`worlds.csv` と `images/001.jpg`〜`050.jpg` のURLを登録できます。実行時のURL生成には依存しません。

写真をInteractすると、選んだワールドのポータルを自分にだけ表示します。同じ写真を再度Interactすると閉じ、別の写真を選ぶと表示するワールドを切り替えます。同時に表示するポータルはPortalControllerごとに1つです。

表示したポータルを選択し、VRChatの画面から自分で新しいインスタンスを作成する形式です。ポータルをくぐって移動する処理はありません。ポータルの共通位置／各写真の位置の切り替えはUnity側で設定します。ワールド情報UIはManagerや操作パネルから一括で表示／非表示を切り替えられます。

CSVと画像の読み込み、再読み込み、情報UIの表示はローカルです。ほかのユーザーへReloadを同期しません。画像は順番に読み込むため、写真の表示には時間がかかります。

ManagerのInspectorでは、遠くの画像を解放する設定も選べます。写真ごと、または同じ列のグループごとに近づいた画像を読み込み、離れた画像を解放します。初期設定はOFFです。解放後に再接近すると同じURLから再取得します。列グループの設定はUnity側で行い、CSVへの項目追加は不要です。

## 更新フロー

```text
写真を追加・変更
↓
worlds.csvを編集
↓
Commit / Push
↓
GitHub Pages更新
↓
VRChat側で再読み込み
```

入室時の自動読み込みが有効な場合は、設定された待機時間の後にCSVと画像を読み込みます。

## 注意

- Repository名やGitHubユーザー名を変更すると、公開URLが変わる場合があります。
- `worlds.csv`、`images` フォルダ名、画像の命名規則は、運用開始後はなるべく変更しないでください。
- 公開先・ファイル名・拡張子を変更する場合は、Unity側の登録URLの変更とワールドの再Uploadが必要です。
- GitHub Pagesへ置いた画像やCSVは公開情報として扱ってください。
- 画像差し替え直後は、キャッシュの影響で古い画像が表示される場合があります。
- 存在しないワールドや、ユーザーがアクセスできないワールドへの移動は保証されません。公開前に対象ワールドとポータルの選択動作を確認してください。
- このCSVはPhoto_Galleryの `gallery.csv` と項目が異なります。そのまま流用せず、`worlds.csv` の形式に合わせてください。

## 用途

- おすすめワールドの紹介
- ワールド巡りの記録
- イベント会場の案内
- ワールド制作者の作品紹介
- 横長／縦長のスクリーンショット展示
